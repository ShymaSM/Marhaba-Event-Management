# Marhaba Event Management

A responsive, single-page website for **Marhaba Event Management**, a professional event planning and management company based in Tamil Nadu. The site showcases services, packages, and a gallery, and allows visitors to submit enquiries directly through a contact form.

## 🌟 Features

- **Responsive Design** – Fully optimized layout for desktop, tablet, and mobile devices
- **Sticky Navigation Bar** – Smooth-scrolling navigation with scroll-aware styling
- **Hero Section** – Eye-catching landing section with call-to-action buttons
- **About Section** – Company mission, vision, and core values
- **Services & Event Packages** – Detailed modals for events such as weddings, birthday parties, and corporate functions
- **Filterable Gallery** – Category-based image filtering with smooth animations
- **Testimonials Slider** – Auto-scrolling customer testimonials with manual navigation
- **Contact / Enquiry Form** – Client-side validation for name, mobile number, email, event type, date, budget, and message
- **Floating Action Buttons** – Quick-access call and WhatsApp buttons
- **Scroll Animations** – AOS (Animate On Scroll) integration for smooth section transitions
- **SEO & Social Sharing** – Meta tags and Open Graph tags for better discoverability

## 🛠️ Built With

- **HTML5** – Semantic structure
- **CSS3** – Custom properties (CSS variables), Flexbox, Grid, animations, and media queries
- **JavaScript (Vanilla)** – DOM manipulation, form validation, gallery filtering, testimonial slider, and smooth scrolling
- **AOS Library** – Scroll-based animations
- **Font Awesome** – Icons
- **Google Fonts** – Playfair Display & Poppins

## 📂 Project Structure

This project is built as a **single HTML file** containing embedded CSS and JavaScript for easy deployment and portability.

```
Marhaba_Single_File.html   # Complete website (HTML + CSS + JS)
```

## 🚀 Getting Started

1. Clone or download the repository
2. Open `Marhaba_Single_File.html` in any modern web browser
3. No build steps or dependencies required — runs entirely client-side

## 📋 Form Validation

The enquiry form validates:
- Full name (minimum 3 characters)
- 10-digit mobile number
- Valid email format
- Event type, date, and budget selection
- Message (minimum 10 characters)

Submitted enquiries are stored locally for demo purposes.

## 📱 Responsive Breakpoints

The design adapts across screen sizes with optimized layouts and floating button sizes for mobile devices (≤768px).
